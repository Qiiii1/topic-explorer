使 用 说 明
版本 0.2.0
====================================================================

一、这是什么
--------------------------------------------------------------------
「有点想法」是一个面向设计项目、课程作业和研究选题的网页画布。
它从一个粗糙的想法出发，帮你在画布上把问题逐渐展开：

  · 灵感模式：题目 → 方向 → 方案 → 子方案，向外发散。
  · 梳理模式：沿场景、人群、痛点向内收敛，并把同类卡片组合成新的
    交集，让问题落到具体可做的地方。

每一张卡片都保留「它从哪里来、为什么这样关联」，所以你能随时回看
某条思路是怎么一步步长出来的。

这一版和你可能见过的在线版最大的区别是：
  项目不再自带模型接口。
  没有服务端 API、没有 .env 配置、没有托管后端。
  所有 AI 生成都直接使用你自己在页面右上角填写的模型接口，
  密钥只保存在你这台电脑的浏览器里。

二、快速开始（3 步）
--------------------------------------------------------------------
1) 准备环境
   安装 Node.js 22 或更新版本：https://nodejs.org
   安装时一路默认即可；装完在终端执行 node -v，应显示 v22 或更高。
   本项目没有任何第三方依赖，不需要执行 npm install，也不需要联网
   安装软件包。

2) 启动
   解压后的文件夹里已经准备好启动脚本，任选一种：

   macOS：
     双击「启动.command」。
     如果系统提示“无法打开，因为无法验证开发者”，
     请右键点击它 → 选择「打开」→ 再点「打开」。
     仍然不行时，在该文件夹的终端里执行：
         chmod +x 启动.command
         ./启动.command

   Windows：
     双击「启动.bat」。

   或者用命令行（所有系统通用）：
         cd 解压后的文件夹
         npm start

   启动成功后终端会显示：
         有点想法 · 选题与灵感画布
         服务地址：http://127.0.0.1:4178
   macOS 双击「启动.command」会自动打开浏览器；用 npm start 或
  Windows 的「启动.bat」时，请手动在浏览器里打开上面这个地址。

3) 配置 AI
   点击页面右上角的「API 配置」，填写自己的接口地址、API Key 和
   模型 ID，点「保存并验证」。看到状态点变成绿色、按钮显示模型名，
   就可以开始生成了。
   具体字段与常见报错见本说明第四节。

   第一次打开也可以先点「打开项目」，用示例画布熟悉操作；
   示例不调用模型，不消耗你的额度。

重要：必须通过上面的本地服务访问页面。
      直接双击 app/index.html（file:// 地址）无法运行，因为页面使用
      ES 模块、并从浏览器直接请求模型接口，浏览器会拦截这种访问。

三、文件说明
--------------------------------------------------------------------
项目主要入口有三个：
  · 页面入口：app/index.html
  · 程序入口：app/app.js
  · 服务入口：server.mjs（只负责把 app/ 目录当成网站提供出来）

目录结构：

  启动.command          macOS 启动脚本（等同于 npm start）
  启动.bat              Windows 启动脚本（等同于 npm start）
  server.mjs            本地静态文件服务器：监听 127.0.0.1:4178，
                        只发送 app/ 目录里的文件，不提供任何 AI 接口，
                        不读取环境变量，也不联网。
  package.json          项目信息与脚本（start / dev / test / check）
  README.md             GitHub 风格的项目说明
  使用说明.txt           本文件
  LICENSE               开源许可（MIT）

  app/                  网页本体，全部是静态文件
    index.html          页面入口，只有 #app、#overlays 等容器
    app.js              主程序：界面渲染、画布交互、生成流程、导入
                        导出、分享与快捷键，都在这里
    domain.js           数据模型：项目结构、校验、两种模式画布切换、
                        节点布局与自动整理
    browser-model.js    浏览器端 AI 客户端：直接请求你自己配置的模型
                        接口，并把配置保存到本机 localStorage
    model-protocol.js   提示词、请求体与返回结果的格式校验，以及把
                        服务商错误翻译成中文提示
    inspiration.js      灵感模式的三阶段生成与阶段校验
    inspiration-rules.js 灵感模式的选材规则与提示词片段
    demo.js             示例画布的预置卡片
    card-editing.js     卡片编辑面板
    canvas-gestures.js  画布拖动、缩放、框选等手势
    generation-history.js 生成批次记录与撤销/重做
    scene-categories.js 场景分类与配色
    home-logo.js        首页 Logo 的动画组件
    styles.css          基础样式、布局与响应式规则
    interactions.css    交互组件样式、API 配置入口与弹窗样式
    liquid-glass-ui.css 液态玻璃质感的工具栏与控件
    vendor/             第三方小体积脚本（本地文件，无需联网）
    assets/             图标、Logo、品牌图等静态资源

  reference/            设计稿与设计说明（仅作资料，不影响运行）
  test/                 自动化测试（node --test，可离线运行）

说明：app/ 目录里的文件通过相对路径互相引用，移动时请整体移动，
      不要只拷贝单个文件。

四、AI 接口配置（重要）
--------------------------------------------------------------------
入口位置：
  · 首页：右上角的「API 配置」按钮
  · 工作区：顶部工具栏最右侧的「API 配置」按钮
  （两者是同一个入口；按钮上的圆点变绿表示已连接。）

需要填写四项：

  1) 模型服务
       选择「DeepSeek 官方」或「其他兼容服务」。
       只是界面预设，不影响实际请求地址；选错也可以手动改地址。

  2) API 地址
       填服务的基础地址，不要带 /chat/completions。
       DeepSeek 官方：https://api.deepseek.com
       其他兼容 OpenAI 接口的服务：填它文档里的 base URL，
       例如 https://api.openai.com/v1 。
       除本机地址外必须使用 HTTPS；http://localhost、http://127.0.0.1
       也允许，方便对接本地部署的模型服务。

  3) API Key
       在服务商后台创建，通常以 sk- 开头。
       输入框只显示圆点，提交后不会在页面上回显。

  4) 模型 ID
       不同账号可用的模型不同，不要凭猜测填写。
       填好地址和 Key 后，点右侧「读取可用模型」，程序会请求该服务
       的 /models 接口，把可用模型列出来，选一个即可。
       也可以手动输入服务商文档里的模型名称。

保存：
  · 「保存并验证」会先检查配置是否合法；DeepSeek 官方接口还会实际
    请求一次模型列表，确认密钥和模型名称都正确，成功后才会保存。
  · 勾选「在这台浏览器记住配置」：配置写入浏览器 localStorage，
    下次打开自动连接。
  · 不勾选：只在本次页面打开期间有效，刷新后需要重新填写。
  · 「清除配置」：立即从 localStorage 删除密钥和接口信息，状态回到
    未配置。

隐私与安全：
  · 请求由浏览器直接发往你填写的服务商，不经过本项目的任何服务器；
    server.mjs 只发送网页文件，不接收也不会记录密钥。
  · 密钥只存在你这台电脑当前浏览器的 localStorage 中；不会写进
    项目 JSON、导出文件、分享链接，也不会显示在页面上。
  · 分享链接、导出的 JSON / Markdown / PNG / PDF 都不包含密钥。
  · 服务商返回的错误信息会先抹掉密钥再显示（显示为「[已隐藏]」）。
  · 请勿把 API Key 上传到 GitHub、网盘、聊天工具或截图里。
    一旦怀疑泄露，请立刻到服务商后台吊销该 Key 并新建一个。

跨域（CORS）要求：
  浏览器直连服务商，因此对方必须允许跨域访问。
  DeepSeek 官方接口已支持；部分自建或第三方兼容服务可能不允许，
  这时生成会提示：
      「网页无法连接模型服务，请检查网络和 API 地址；其他兼容服务
        需要允许跨域访问（CORS）。」
  解决办法：换用支持 CORS 的服务，或在服务端加上允许跨域的响应头。

常见报错对照：
  · 「请先在右上角配置 AI 接口，再生成卡片。」
        还没保存配置，或已清除配置。
  · 「DeepSeek 未通过密钥验证，请检查 API Key 和模型权限。」
        密钥填错、已吊销，或该 Key 没有此模型的权限。
  · 「DeepSeek 返回余额不足，请检查服务账户。」
        账户余额用完，需要充值。
  · 「DeepSeek 请求过于频繁，请稍后重试。」
        触发限流，等一会儿再试。
  · 「模型名称需要填写 DeepSeek 模型 ID，不是密钥或 UUID。」
        模型 ID 一栏被误填成了密钥或复制来的编号。
  · 「这个模型名称不在服务返回的列表中，请读取可用模型后重新选择。」
        手填的模型名账号不可用。
  · 「模型地址需要使用 HTTPS；本机服务也可以使用 HTTP。」
        地址协议不对。
  · 「模型服务返回了无法读取的内容，请检查 API 地址后重试。」
        地址指向了网页而不是接口。

五、特殊运行要求
--------------------------------------------------------------------
1) Node.js 22 或更新版本。
   只用于启动本地静态服务；项目没有 npm 依赖，不需要联网安装。

2) 浏览器：近两年的 Chrome、Edge、Safari 或 Firefox。
   建议使用最新版，以获得完整的手势、导出与动效支持。

3) 端口：默认 4178，只监听 127.0.0.1（同一局域网的其他设备访问不到）。
   端口被占用时换一个：
       npm start -- --port 4180
   或
       PORT=4180 npm start
   浏览器地址相应改为 http://127.0.0.1:4180 。

4) 网络：打开界面、编辑、导入导出都可以离线完成；
   只有「生成」「组合」和「读取可用模型」需要联网并配置好接口。

5) 不需要的外部工具：
   不需要数据库、不需要 Docker、不需要环境变量文件（.env）、
   不需要 Cloudflare / Vercel 等托管平台。
   导出 PDF 使用浏览器的打印功能（系统自带）。

6) 本包不含任何密钥：
   .env、wrangler 配置、云端 Worker 代码都已移除；
   测试与示例只使用本地模拟服务，不访问真实接口。

7) 数据保存位置：浏览器 localStorage。
   清理浏览器数据、换浏览器、换电脑都会看不到原有项目。
   重要项目请先用「导出 → JSON」备份，再在新环境「打开项目 → 导入」。

六、功能与交互
--------------------------------------------------------------------
1) 首页
   新建探索：输入一两句粗想法，进入画布。
   打开项目：列出本机保存的项目，可导入导出的 JSON。
   右上角：API 配置入口。

2) 两种模式
   灵感模式：题目 → 方向 → 方案 → 子方案。
      · 题目下的「+」生成 3 / 6 / 10 个方向；
      · 方向下生成方案，方案下继续生成子方案；
      · 卡片会带上方法依据、保留点、改动点等元数据。
   梳理模式：沿场景、人群、痛点逐层细化。
      · 画布上悬浮维度卡片，点某一维度即在该维度下生成；
      · 连接点拖到另一张同类卡片上，可生成保留两侧条件的交集。

   模式切换：底部「灵感模式 / 梳理模式」按钮；
   也可以打开卡片右上角「…」，把它作为中心转到另一种模式，
   转换时会带上原题、项目条件与上游卡片。

3) 生成
   卡片下方（或右侧）的「+」按钮触发；
   生成前会显示扫光占位卡片并预留空间，避免卡片互相重叠；
   生成中可取消；失败会给出可读的错误提示，不会写入半成品。

4) 编辑与查看
   卡片左上角铅笔按钮：改标题、描述和「关联理由」；
   修改后的内容会作为下一次生成的上下文。
   单击卡片：右侧面板显示来路、直接下一级和理由；
   画布会高亮它的完整上游路径。

5) 收藏
   拖动顶部绳子拉下收藏架；
   点卡片可翻转放大查看，点星标取消收藏。
   收藏保存的是节点快照 + 全部上游路径 + 理由。

6) 画布操作
   框选              拖动空白处；Shift 拖框加选
   增减选择          Shift 点击卡片
   全选 / 清空       ⌘/Ctrl + A；Esc
   平移              触控板双指滑动；空格 + 拖动；鼠标中键拖动
   缩放              触控板捏合；Command + 滚轮；底部缩放按钮
   微调位置          方向键
   删除所选          Delete / Backspace（题目保留）
   撤销 / 重做       ⌘/Ctrl + Z；⌘/Ctrl + Shift + Z
   整理             底部「收起分支 / 显示分支 / 只看分支」
   拖动分支          拖动卡片时，其下游会一起移动

   撤销只记录本次会话的 AI 生成、组合与删除；
   移动、整理、编辑、收藏不占用撤销记录。

7) 导出与分享
   导出：整个项目或框选范围；格式 JSON、Markdown、PNG，
         也可用浏览器打印为 PDF。
   分享：生成包含项目快照的链接；对方打开后得到独立副本，
         不包含你的 API Key。
   选区 JSON 可以重新导入，成为新的探索。

七、常见问题
--------------------------------------------------------------------
问：双击「启动.command」没反应。
答：右键 → 打开，允许运行一次；或在终端执行
    chmod +x 启动.command 后再运行。
    若提示“端口已被占用”，换端口：npm start -- --port 4180。

问：页面能打开，但点生成没反应。
答：先看右上角按钮是否显示模型名。若显示「API 配置」，说明还没配置；
    若显示模型名仍失败，按提示检查 Key、模型名、余额与网络。

问：换了电脑/浏览器，项目不见了。
答：项目保存在浏览器本地，不会跟随账号同步。
    在原环境「导出 → JSON」，到新环境「打开项目 → 导入」。

问：分享链接会不会泄露密钥？
答：不会。链接只包含画布内容快照。

问：可以用哪些模型？
答：任何兼容 OpenAI Chat Completions 接口、且允许浏览器跨域访问的
    服务。DeepSeek 官方已内置预设；其他服务填对应 base URL 即可。

问：能部署到服务器给多人用吗？
答：可以，把整个文件夹放到任意静态托管上，并保证访问地址是
    HTTPS（浏览器要求 HTTPS 才能安全调用接口）。
    注意：每个人都需要自己配置 API Key；由于配置存在各自的浏览器里，
    所以不会互相串用。

八、开发者信息
--------------------------------------------------------------------
   npm start            启动本地服务
   npm run dev          改动后自动重启
   npm test             运行测试（离线，使用本地模拟服务）
   npm run check        语法检查
   npm run validate     语法检查 + 测试

代码分层约定：
  · domain.js 只处理数据与布局，不碰 DOM 和网络；
  · model-protocol.js 负责提示词与结果格式，不关心界面；
  · browser-model.js 负责与模型服务通信与配置存储；
  · app.js 负责界面、交互与流程编排。
修改后建议先跑 npm run validate。
